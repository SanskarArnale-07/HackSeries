1. Executive Summary & System Mission

The rapid proliferation of mega-constellations and fragmentation debris in Low Earth Orbit (LEO) has intensified the risk of catastrophic hypervelocity on-orbit collisions. Operational orbital safety centers must screen thousands of candidate close approaches daily with deterministic mathematical guarantees.

TRAJACTRA delivers a lean, high-velocity, deterministic conjunction screening pipeline designed for high-stakes operational situational awareness. Built during an intensive 8-hour engineering sprint, the platform screens a bounded catalog of 50 to 200 operational LEO satellites and debris objects, computes exact Time of Closest Approach (TCA) and Geometric Miss Distance, and provides mission operators with a cinematic 3D operations console.

Core Architectural Baseline
The core MVP operates completely offline, air-gapped, and subscription-free. It requires zero API keys, relies on analytical astrodynamics, and strictly avoids unverified synthetic probability models.

1.1 Inviolable Scientific & Operational Rules

  • Rule 1: Zero Machine Learning Training or Inference: Orbital mechanics in TRAJACTRA is governed strictly by analytical perturbation physics (SGP4/SDP4) and Euclidean vector mathematics in NumPy. No neural regressors or hallucinated trajectories.
  • Rule 2: Absolute Prohibition of "Collision Probability" (Pc) Claims: Publicly distributed Two-Line Element (TLE) sets do not contain 3D position covariance error matrices (P). Generating an arbitrary synthetic covariance creates statistically invalid risk scores. All proximity metrics are transparently labeled as Geometric Miss Distance (km) or Screening Alert Tiers.
  • Rule 3: Decoupled Coordinate Transformations: Orbit propagation is computed in the True Equator, Mean Equinox (TEME) inertial frame. Geospatial display rotates TEME into Greenwich Earth-Centered, Earth-Fixed (ECEF) coordinates and projects to WGS-84 geodesy exclusively on the backend.
  • Rule 4: Zero External Network Dependency: Every upstream external network call to CelesTrak or NOAA SWPC enforces a strict ≤ 2.5s timeout and instantly falls back to committed local snapshot fixtures in data/fixtures/.
  • Rule 6: Error Code Preservation: Decayed objects or numerical propagation singularities preserve their SGP4 error status (e.g. DECAYED) and are marked invalid, never replaced with synthetic [0,0,0] coordinates at Earth's core.

2. Astrodynamics & Conjunction Screening Pipeline

The computational core implements a three-stage temporal and spatial screening pipeline to achieve sub-second execution across N(N-1)/2 satellite pairs without missing close approaches.

2.1 Three-Stage Screening Algorithm

Stage Filter Name Mechanism & Mathematical Threshold Performance Impact
Stage 1 Geometric Radial Apogee / Perigee Filter Compares orbital radial shells: rp,A − ra,B > Dthresh + 20 km or rp,B − ra,A > Dthresh + 20 km. Discards 70%–85% of non-intersecting orbital pairs in < 5 ms.
Stage 2 Coarse Temporal Proximity Trigger Samples TEME separation d(tk) = ||rA(tk) − rB(tk)|| on a 60-second time grid over 24 hours. Triggers fine search if d(tk) ≤ 500.0 km (accounting for vrel ≤ 15.0 km/s). Eliminates temporal blindspots between steps while rejecting flat-plateau intervals.
Stage 3 Golden-Section Minimization (Exact TCA) Evaluates candidate time intervals [tk-1, tk+1] using Golden-Section search (φ ≈ 0.6180339) down to a temporal tolerance of Δt ≤ 1.0 second. Computes exact 3D encounter coordinates and relative velocity. Computes exact miss distance minima with microsecond numerical precision.

2.2 Relative Velocity Decomposition & Coriolis Kinematics

The relative velocity vector vrel = vA − vB is computed in the inertial TEME frame. Transforming into the rotating Earth-Centered Earth-Fixed (ECEF) frame requires applying the kinematic Coriolis rotation correction: 

v_ecef = R_z(theta_gmst) * v_teme - omega_earth x r_ecef

where ωearth = [0, 0, 7.292115 × 10−5] rad/s. Both vectors are explicitly output in API payloads.
